IT Helpdesk AI Assistant
Overview
This project demonstrates a simple AI-powered IT Helpdesk Assistant built using Google Gemini.

The assistant provides support for:

Microsoft Intune
Microsoft Teams
Microsoft Entra ID
Microsoft 365
Windows Autopilot
Objective
The goal of this project was to gain hands-on experience with:

AI Agents
Knowledge Bases
Prompt Design
AI Testing
Knowledge Grounding (RAG)
Architecture
User Question ↓ Gemini Agent ↓ Knowledge Base ↓ Relevant Information Retrieved ↓ Response Generated
