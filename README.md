IT Helpdesk AI Assistant
Overview
This project demonstrates a simple AI-powered IT Helpdesk Assistant built using Google Gemini.

The assistant provides support for:

Microsoft Intune
Microsoft Entra ID
Microsoft Teams
Microsoft 365
Windows Autopilot
Key Features
Knowledge-based responses
IT support troubleshooting
Custom knowledge grounding
Step-by-step guidance
Hallucination reduction through approved documentation
Technologies Used
Google Gemini
Google Cloud Platform
Gemini Agent Builder
Cloud Storage
Learning Objectives
The goal of this project was to understand:

AI Agents
Knowledge Bases
Retrieval-Augmented Generation (RAG)
Prompt Design
Agent Testing
AI Governance Concepts
Status
Proof-of-concept project created for AI and automation learning.
